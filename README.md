# 最高温度関連グラフ作成ツール

射出成形の温度センサー（HA-V05）の波形から抽出した特徴量のCSVを読み込み、
成形条件（キャビティ厚み・加熱シリンダ温度・射出速度）ごとのグラフを Excel にまとめて出力する Jupyter ノートブック群です。

- 同じ条件のショットの中で外れた値（外れ値）を自動で見つけ、グラフに × で表示します。
- 外れ値を除いてから描き直したグラフの Excel（外れ値なし描画）も、あわせて出力します。
- 外れ値を除いたCSVや、グラフにした平均値・標準偏差のCSVも出力します。
- 複数の出力結果（Excel）のグラフを、軸をそろえて1つのPDFに並べ、比較することもできます。
- 入力CSV（加工対象ファイル）は読み込むだけで、変更しません。

## 2. 準備（初回のみ）

### 必要なもの
- Windows（ファイル選択ダイアログと日本語フォント「Yu Gothic」などを使うため）
- [VS Code](https://code.visualstudio.com/) と拡張機能「**Python**」「**Jupyter**」（どちらも Microsoft 製）
- [uv](https://docs.astral.sh/uv/getting-started/installation/)（Python とライブラリをまとめて入れるツール）

### 手順
1. **uv をインストール**します。PowerShell で次を実行してください。
   ```powershell
   powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
   ```
   インストール後、PowerShell を開き直すと `uv` コマンドが使えます。
2. **プロジェクトフォルダで環境を作ります。** VS Code でこのフォルダを開き、ターミナル（`Ctrl + @`）で次を実行します。
   ```powershell
   uv sync
   ```
   `.venv` フォルダが作られ、Python 3.13 と必要なライブラリ（pandas / matplotlib / xlsxwriter / openpyxl / ipykernel）が入ります。
3. **カーネルを選びます。** `コードフォルダ` のノートブックを開き、右上の「カーネルの選択」から `.venv` の Python 3.13 を選びます（表示名が `ondograph` になっていることもあります）。

> **uv を使わない場合**
> Python 3.13 を [python.org](https://www.python.org/downloads/) から入れたうえで、プロジェクトフォルダで次を実行し、手順3と同じようにカーネルを選んでください。
> ```powershell
> py -3.13 -m venv .venv
> .venv\Scripts\python -m pip install ipykernel matplotlib pandas xlsxwriter openpyxl
> ```

> **他のPCからコピーした `.venv` がある場合**
> そのままでは動かないことがあります。`.venv` フォルダを削除してから `uv sync` をやり直してください。

## 3. 入力データ（CSV）

- **1行が1ショット**のデータです。同じ条件（厚み・温度・速度の組み合わせ）のショットが複数行あります。
- 文字コードは UTF-8（BOM 付きでも可）か Shift_JIS です。
- 次の列が必要です。足りないファイルは「カラムが見つかりません」と表示されてスキップされます。

| 列名 | 内容 |
|---|---|
| `元ファイル` | 元の波形ファイル名。**先頭の数字がショット番号**（例: `025_190℃_010_2.0mm.csv` → 025） |
| `キャビティ厚み[mm]` | 条件: 厚み |
| `加熱シリンダ温度[℃]` | 条件: 温度 |
| `射出速度[mm/s]` | 条件: 速度（グラフの横軸） |
| `(1)HA-V05_最高値(℃)` | 最高温度 |
| `(1)HA-V05_最高値の時間(s)` | 最高温度になった時刻 |
| `(1)HA-V05_0.7秒前の値(V)` | 最高値の0.7秒前の値 |
| `(1)HA-V05_0.7秒前の時間(s)` | 最高値の0.7秒前の時刻 |
| `(1)HA-V05_立ち上がり値(V)` | 立ち上がりと判定した値（しきい値 2.0V 付近） |
| `(1)HA-V05_立ち上がり時間(s)` | 立ち上がり時刻 |

**mixPP のCSV** は一部の列名が違うため、コードの中で次のように読み替えています。

| mixPP の列名 | 読み替え先 |
|---|---|
| `最高値換算結果(℃)` | `(1)HA-V05_最高値(℃)` |
| `(1)HA-V05_抽出ピーク時間(s)` | `(1)HA-V05_最高値の時間(s)` |

mixPP の `(1)HA-V05_最高値(V)` は電圧なので使いません。

## 4. 各コードの説明

### 共通の使い方

### 01_最高温度関連グラフ作成.ipynb（平均±標準偏差）
- **選ぶもの**: CSVファイル（複数可）
- **出力**:

  | ファイル | 内容 |
  |---|---|
  | `グラフ出力結果_{元のファイル名}.xlsx` | グラフ（下の「Excel の中身」を参照） |
  | `グラフ出力結果_外れ値なし描画_{元のファイル名}.xlsx` | 外れ値を除いてから描き直したグラフ（下の「外れ値なし描画の Excel」を参照） |
  | `グラフ画像_{元のファイル名}/` | Excel のグラフを1枚ずつ PNG で保存したフォルダ（下の「グラフ画像フォルダの中身」を参照） |
  | `グラフ画像_外れ値なし描画_{元のファイル名}/` | 外れ値なし描画の Excel のグラフを、同じように1枚ずつ保存したフォルダ |
  | `外れ値除外_{元のファイル名}.csv` | 全項目について、外れ値のセルだけを空欄にしたCSV（「5. 外れ値の扱い」を参照） |
  | `最高値外れ値行除外_{元のファイル名}.csv` | `(1)HA-V05_最高値(℃)` が外れ値だったショット（行）だけを除いたCSV。他の項目の外れ値は残します。 |
  | `グラフ用統計値_{元のファイル名}.csv` | グラフにした6項目それぞれの `{項目名}_平均値`・`{項目名}_標準偏差上`（平均＋標準偏差）・`{項目名}_標準偏差下`（平均－標準偏差）。1行が1条件（厚み・温度・速度）です。 |

- **Excel の中身**:
  - 6項目（最高値、最高値の時間、0.7秒前の値、0.7秒前の時間、立ち上がり値、立ち上がり時間）ごとに1シートです。
  - 各シートには、上から次の3つの部分があります。
    1. 「キャビティ厚みごとのグラフ」: 厚みごとに次を並べます。
       - 温度ごとの単一グラフ（平均と標準偏差の誤差棒）
       - 全温度を重ねた統合グラフ
    2. 「加熱シリンダ温度ごとのグラフ（全厚み統合）」: 温度ごとに、全厚みの平均値を重ねた統合グラフを並べます。
    3. 「加熱シリンダ温度ごとのグラフ（全厚み統合）_エラーバー付き」: 2. と同じグラフに、平均±標準偏差のエラーバーを付けたものです。
  - 外れ値の × の横に、× と同じ色でショット番号（例: `025`）を表示するのは、単一グラフと、2.・3. のグラフです。
  - 横軸はすべて射出速度です。
  - 線の色とマーカーは、温度・厚みの値ごとに決まっています（例: 厚み 0.5mm は青の●）。別のファイルのグラフと見比べても、同じ色は同じ温度・厚みを表します。
  - グラフの6シートの後ろに、**グラフの数値のシート**が2枚あります。04 の比較では、この2枚から数値を読んでグラフを描き直します。
    - `グラフ用統計値`: `グラフ用統計値_` のCSVと同じ内容です。
    - `外れ値`: 外れ値の一覧です（元ファイル・条件・項目・値）。外れ値がなければ見出しだけです。
- **外れ値なし描画の Excel**（`グラフ出力結果_外れ値なし描画_～.xlsx`）:
  - 項目ごとに、外れ値のセルだけを除いたデータ（`外れ値除外_` のCSVと同じ）で平均・標準偏差を計算し直し、上と同じ並びでグラフを描きます。
  - 除いた外れ値はグラフに描きません（× もショット番号もありません）。グラフのタイトルには「・外れ値なし描画」が付きます。
  - 外れ値を除いたあとに、外れ値を探し直すことはしません。
  - 数値のシートは3枚です。
    - `グラフ用統計値`: 外れ値を除いて計算した平均値・標準偏差上・下です。
    - `外れ値`: このExcelのグラフには × で描いた外れ値がないので、見出しだけです。
    - `除外した外れ値`: 計算から除いた外れ値の一覧です（通常の Excel の `外れ値` シートと同じ内容です）。
- **グラフ画像フォルダの中身**:
  - `グラフ画像_{元のファイル名}/`（外れ値なし描画は `グラフ画像_外れ値なし描画_{元のファイル名}/`）の中に、Excel のシート名と同じ名前のフォルダが6個あります（例: `(1)HA-V05_最高値(℃)/`）。
  - 各フォルダには、そのシートのグラフが1枚ずつ PNG で入っています（Excel に貼ったものと同じ画像です）。ファイル名の先頭の数字は、上の「Excel の中身」の 1.〜3. に対応します。

    | ファイル名 | グラフ |
    |---|---|
    | `1_厚み{厚み}mm_{温度}℃_単一.png` | 1. の単一グラフ |
    | `1_厚み{厚み}mm_全温度統合.png` | 1. の全温度統合グラフ |
    | `2_温度{温度}℃_全厚み統合.png` | 2. の全厚み統合グラフ |
    | `3_温度{温度}℃_全厚み統合_エラーバー付き.png` | 3. のエラーバー付きグラフ |

  - 同じ名前の画像は上書きされます。データの条件が減って作られなくなった画像は、古いものが残ります（気になる場合はフォルダごと削除してから実行してください）。
- 通常の Excel の平均・標準偏差は、**外れ値も含めた**全ショットで計算します（`グラフ用統計値_` のCSVも同じ値です）。外れ値を除いた値は、外れ値なし描画の Excel の `グラフ用統計値` シートにあります。
- `外れ値除外_` と `最高値外れ値行除外_` のCSVは、列名が元のCSVと同じです（mixPP も `最高値換算結果(℃)` などのまま）。`グラフ用統計値_` のCSVの項目名は、グラフと同じ標準名（例: `(1)HA-V05_最高値(℃)`）です。

### 04_グラフ出力結果の比較.ipynb（01 の結果の比較）
- **選ぶもの**: 01（または03）で作った `グラフ出力結果_～.xlsx`（複数）と、PDFの保存先
- **選び方**:
  - 1回のダイアログでは、同じフォルダの中のファイルしか選べません。
  - 選ぶたびに「別のフォルダのファイルも追加しますか？」と聞かれるので、「はい」で別のフォルダのファイルを追加し、「いいえ」で選択を終えます。
  - 通常の Excel と外れ値なし描画の Excel の**どちらを選んでもかまいません**。同じフォルダにあるもう片方も自動で読み込み、同じ元ファイルの2つは1組として扱います。
  - 一時ファイル（`~$` で始まるもの）と、同じファイルを2回選んだ分は除かれます。
- **出力**: 比較用のPDF 2つ（保存ダイアログで選ぶ名前は1つです）

  | PDF | 中身 |
  |---|---|
  | 選んだ名前（初期は `グラフ比較結果.pdf`） | 通常の Excel（外れ値あり）の比較。外れ値は × で表示します。 |
  | 選んだ名前の後ろに `_外れ値なし描画` を付けた名前（`グラフ比較結果_外れ値なし描画.pdf`） | 外れ値なし描画の Excel の比較。外れ値を除いて計算した値で、× は描きません。 |

  - どちらも**1項目につき2ページ**で、全部で12ページです。項目ごとに「全厚み統合」→「全厚み統合_エラーバー付き」の順に並びます。
  - 各ページに、**行 = 選んだファイル、列 = 加熱シリンダ温度** でグラフを並べます。ファイルは置き場所（フォルダ名）の順に並び、各グラフのタイトルに「フォルダ名 / ファイル名」と温度が入ります。
  - 各グラフの中身は、01 の Excel の「加熱シリンダ温度ごとのグラフ（全厚み統合）」「…_エラーバー付き」と同じです。
    - 厚みごとの平均値の線と、外れ値の × を描きます。× の横には、× と同じ色でショット番号を表示します。
    - エラーバー付きのページでは、平均±標準偏差のエラーバーも描きます（値は Excel の `グラフ用統計値` シートの標準偏差上・下です）。
  - **縦軸・横軸の範囲は、そのページのすべてのグラフで同じ**です。線の高さや位置を、そのまま見比べられます。
  - 凡例は、ページの右上に1つだけあります。
  - そのファイルにない温度のマスには「データなし」と表示します。
- **ファイルによって、含まれる射出速度が違います。** 3data と 5data には同じ速度の条件がないので、グラフの線は横軸の別の範囲に描かれます。

  | データ | 射出速度 [mm/s] |
  |---|---|
  | all / Alldata | 3〜320（全12速度） |
  | 3data | 3・5・280・320 |
  | 5data | 10〜240 |

- **使えるのは、グラフの数値のシートが入った Excel だけです。** 次の Excel は「スキップ」になります。
  - 01 に数値のシートを追加する前（2026年10月9日より前）に作った Excel → 03（または01）で作り直してください。
  - 02 で作った Excel（`グラフ出力結果_10shot_～.xlsx`）
- 外れ値なし描画の Excel がないとき（01 に外れ値なし描画を追加する前に作った Excel など）は「なし」と表示され、そのファイルは外れ値ありの PDF だけに入ります。
- 選んだ Excel は読み込むだけで、変更しません。
- 04 は、グラフの色やフォントなどの設定を 01 のノートブックから読み込みます。そのため **04 は 01 と同じフォルダに置いてください**。

## 5. 外れ値の扱い

### 判定方法
同じ条件（厚み・温度・速度が同じ）のショットの中で、項目ごとに判定します。次の**両方**を満たす値を外れ値とします。

1. **統計的に大きく外れている**: 修正zスコア `0.6745 × |値 − 中央値| / MAD` が **3.5** を超える。
   - MAD は「中央値からのずれ」の中央値です。
2. **実用上も大きくずれている**: 中央値からのずれが、単位ごとの最小値を超える。
   - ℃ の項目は **1.0**、s（秒）の項目は **0.1**、V の項目は **0.05**。

2つ目の条件がないと、0.004秒や0.2℃といった意味のない小さなずれまで外れ値になってしまいます。
基準は、01・02 のセル1にある `OUTLIER_Z` と `OUTLIER_MIN_DEV` で変更できます。

### 出力への反映
- **グラフ**:
  - 外れ値を系列と同じ色の × で重ねて描き、凡例に「外れ値」を加えます。
  - 次のグラフでは、× の横に同じ色でショット番号（例: `025`）も表示します。
    - 01 の単一グラフ
    - 01 の「加熱シリンダ温度ごとのグラフ（全厚み統合）」と、その「_エラーバー付き」
    - 04 の比較グラフ
- **外れ値なし描画の Excel**（`グラフ出力結果_外れ値なし描画_`）:
  - 外れ値のセルを除いてから平均・標準偏差を計算し直して描きます。除いた外れ値は描きません。
  - どのデータを除いたかは、`除外した外れ値` シートで確認できます。
- **画面**: セル2の実行時に、外れ値の一覧（元ファイル・条件・項目・値）を表示します。
- **外れ値除外CSV**（`外れ値除外_`）:
  - 全項目について、外れ値になった**セルだけ**を空欄にします。行や他の項目は残し、列名も元のままです。
  - 外れ値なし描画の Excel は、このCSVと同じデータから描いています。
  - このCSVを 01 に入力し直すこともできますが、その場合は外れ値を探し直すため、新しく外れ値が見つかって × が付くことがあります（外れ値なし描画の Excel は探し直しません）。
- **最高値外れ値行除外CSV**（`最高値外れ値行除外_`）:
  - `(1)HA-V05_最高値(℃)` が外れ値だったショットだけを、**行ごと**除きます。
  - 他の項目の外れ値は除かず、そのまま残します。
  - 最高温度に注目して、外れたショットを丸ごと除いたデータを使いたいときに使います。

### 限界
同じ条件の**全ショットが同じように**おかしい場合（例: ピーク抽出がすべて失敗している）は、外れ値として検出できません。
この種の異常は、次の「ピーク抽出失敗の疑い」の警告で確認してください。

## 7. 注意点・よくあるトラブル

- **出力ファイルを Excel で開いたまま実行するとエラーになります。** Excel を閉じてから実行し直してください（03 ではそのファイルだけ「エラー」になります）。
- **04 で、保存先と同じ名前のPDFを開いたまま実行すると保存できません。** PDF を閉じてから、セル3を実行し直してください。
- **01・03 は、1つのCSVにつき2つの Excel（通常と外れ値なし描画）と約260枚のグラフ画像を作るため、少し時間がかかります。** 03 でデータフォルダ全体を処理するときは、終わるまで待ってください。
- **出力はデータフォルダの中に作られ、同じ名前のファイルは上書きされます。** 残しておきたい結果は、別の名前で保存しておいてください。なお、入力CSVは読み込むだけで、変更・上書きされることはありません（出力名には必ず接頭辞が付きます）。
- **外れ値除外CSVなどの出力を入力にすると**、出力名は `外れ値除外_外れ値除外_…` のようになります。また、外れ値を除いたことで中央値などが変わるため、新しく外れ値が見つかることがあります。
- **03・04 が「01_最高温度関連グラフ作成.ipynb が見つかりません」と表示するとき**は、03・04 と 01 が同じフォルダにあるか確認してください。VS Code でノートブックを開いて実行すれば、通常はノートブックのあるフォルダが基準になります。
- **グラフの日本語が「□」になるとき**は、Windows の日本語フォント（Yu Gothic・Meiryo など）がない環境です。Windows で実行してください。
